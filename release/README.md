# MOVE 28 发布边界

`runtime-manifest.json`是参与者发布包的唯一文件白名单。后续构建维护备份或HTTPS发布候选时，必须从已提交的明确版本按该清单复制文件，禁止直接打包整个工作区。

## 允许进入参与者包

- `index.html`、`.nojekyll`；
- `index.html`实际加载的`src/`经典脚本和`assets/css/`样式；
- 跟练界面明确引用的4段本地音乐；
- README、维护者说明和3份试用文档。

## 明确排除

- `assets/gifs/`和`assets/exercises/`：旧GIF及正式媒体审核台账，不是参与者运行时输入；
- `media-build/`、`media-src/`：研究候选、源素材和生成中间件；
- `docs/research/`、`docs/plans/`、handoff、产品研究资料；
- `tests/`、`scripts/`、依赖、测试报告、缓存和版本控制数据。

研究报告可以保留在源码或本机研究区用于审计，但不因此获得参与者发布资格。任何新增运行时文件都必须同时更新白名单及其行为测试；禁止使用`git add .`或直接压缩项目根目录作为发布流程。

本清单只定义边界，不代表已经生成、部署或批准发布候选。正式构建仍需生成逐文件SHA-256清单，从全新解压目录验证HTTP和`file://`流程，并在获得明确授权后才能推送或部署HTTPS。
