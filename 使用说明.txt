MOVE 28 维护者离线说明
========================

一、参与者入口
--------------
参与者必须使用维护者提供的、可转发的 HTTPS 试用网址。
ZIP、压缩包预览和 file:// 不能作为参与者主要入口。
当前阶段不自动发布，也不覆盖稳定站点。

二、本地备份/恢复预览
--------------------
1. 保持 index.html、assets、src 的相对目录结构不变。
2. 可直接双击 index.html 验证 file:// 兼容性；不要在压缩包预览窗口打开。
3. 更推荐在完整目录运行：
   python -m http.server 8765 --bind 127.0.0.1
4. 浏览器访问：
   http://127.0.0.1:8765/index.html
5. file:// 或本地服务器仅用于维护、恢复和发布前测试。

三、完整试用流程
----------------
问卷 -> 三屏能力校准（五项非极限、可跳过） -> 固定4周候选计划
-> 完整规则校验 -> 人工一致性复核 -> 开放训练
-> 每周复盘 -> 接受调整后重新人工复核。

问卷通过后不会立即开放训练。能力档案和候选计划必须绑定当前
intake revision 与 capability revision；任何健康红旗、警示症状、
能力/器械不匹配或校验失败均应阻断。

四、数据和隐私
--------------
问卷、能力档案、计划与记录默认只保存在当前浏览器。
切换浏览器、清理站点数据、使用无痕模式或更换设备可能丢失记录。
“本机数据与隐私”可下载最小化复核摘要，或删除当前浏览器中的
MOVE 28 数据；已下载文件需自行删除。

五、运行发布门禁
----------------
npm install
npm run test
npm run test:e2e
npm run test:all

tests/e2e/offline-file.spec.cjs 和 offline.spec.cjs 必须通过，确保
index.html 引用的全部本地 classic script 与样式、动作目录引用的全部 GIF、
4 段音乐和原生 file:// 路径完整。
任何安全、隐私、能力约束、计划校验、人工复核或运行时停止测试失败，
都不得交付。

六、故障处理
------------
- 页面无样式/GIF：检查是否移动、遗漏 assets/src，或从压缩包内预览。
- 显示只读示例：确认问卷和能力校准均已保存。
- 没有训练入口：确认候选计划已通过人工复核；不要绕过。
- 音乐失败：允许静音继续；动作与安全停止不应受影响。
- 状态损坏/版本过新：不要覆盖原字节，先记录固定错误提示再处理。
