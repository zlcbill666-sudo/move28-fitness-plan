# MOVE 28｜4周减重入门训练计划

移动端优先的四周训练计划，包含28天安排、17个动作GIF、分阶段音乐跟练、本地追踪和CSV导出。

- 首屏可直接进入5步跟练模式，完成后自动打卡并定位下一天
- 跟练音乐会随热身、力量、有氧和放松环节自动切换，可暂停并调节音量
- 每日记录默认只显示6个常用字段，高级健康记录按需展开
- 有氧统一使用椭圆机／交叉训练机和跑步机0坡度平地慢走
- 页面不预置个人身份、身体数据或训练记录
