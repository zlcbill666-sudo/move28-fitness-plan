# MOVE 28｜4周入门训练试用版

MOVE 28 是一个面向邀请试用用户的 4 周入门训练页面。它会先让你完成安全问卷和五项非极限能力校准，再生成适合当前设备、时间和能力边界的训练安排；确认完成前不会开放训练入口。

## 你会看到什么

- 固定 4 周训练周期，不会自动生成第 5 周。
- 每次训练前会先确认今天的时间、空间、器械和身体状态。
- 每屏只显示一个确定动作，按页面文字步骤执行即可。
- 每个动作都有示范图；示范图只帮助理解姿势，文字步骤、无痛范围和停止信号始终优先。
- 出现胸部不适、晕厥感、异常气短、突发剧痛、无法承重或神经/意识异常时，立即停止训练。
- 每周复盘一次，最多只调整一个受控变量；调整后的新计划也需要重新确认。

## 试用入口

参与者请只使用维护者单独发送的 **HTTPS 试用网址**。

ZIP、压缩包、`file://` 或本地预览不是参与者的正式入口，只用于维护者备份、恢复和发布前检查。如果页面来源不明、不是 HTTPS，或浏览器提示证书风险，请先停止并联系维护者。

## 数据与隐私

问卷、能力档案、计划和训练记录默认只保存在当前浏览器。清理站点数据、切换浏览器、使用无痕模式或更换设备，可能导致记录丢失。

你可以在“本机数据与隐私”区域查看本机保存摘要、下载给确认人看的摘要，或删除当前浏览器中的全部 MOVE 28 数据。已下载到设备上的文件需要你自行删除。

## 维护者本地检查

维护者做本地检查时，请保持 `index.html`、`assets/`、`src/` 和 `docs/` 的相对目录结构不变。可以在完整目录中打开 `index.html`，或在本地启动静态服务后访问 `http://127.0.0.1:8765/index.html`。

本地检查和维护备份不能替代参与者 HTTPS 入口。任何安全、隐私、能力边界、计划确认或运行时停止流程异常，都不应交付给参与者。

## 媒体来源

页面中的动作示范图来自本地动作图库；跟练音乐来自 Mixkit Fitness Music，曲名与作者在播放器中显示。音乐加载失败只会降级为静音，不影响训练步骤与安全停止。
