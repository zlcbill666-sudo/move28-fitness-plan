# MOVE 28 两人试用参与者指南

## 这是什么

MOVE 28 当前是仅邀请两人的本地离线试用版。它使用固定、确定性的安全规则和动作库生成 **4 周起步计划**，不连接云端 AI、账号、数据库或第三方健康分析。

它不是诊断、康复、急救、孕产训练、复杂疾病管理或营养热量处方，也不保证固定期限减重或体型结果。

## 开始前

1. 将指定 ZIP 完整解压到一个新文件夹，不要直接在压缩包预览窗口打开。
2. 双击 `index.html`。
3. 整个试用期间使用同一台设备、同一浏览器和同一浏览器配置。
4. 不使用无痕/隐私模式；不要随意清理浏览器数据。
5. 本轮反馈只发给试用负责人现有的一对一微信会话，不发群聊或公开平台。

## 完成问卷和获得计划

1. 点击“生成我的4周计划”。
2. 独立完成 10 步问卷，工作人员不代答。
3. 返回修改时，只记录“修改了第几步”，不要记录具体健康答案。
4. 最终确认后，数据才保存到当前浏览器。
5. 合格计划会进入“等待人工复核”；复核前没有训练入口。
6. 在隐私区可查看和下载最小审核摘要；它不含原始健康答案。
7. 按指定私密渠道联系复核人。复核通过后刷新页面，才能看到“开始本节训练”。

未完成问卷时看到的是只读示例，不能作为你的训练计划，也不能打卡。

## 4周周期

- 第1周：适应动作和训练节奏。
- 第2周：重复并进行规则允许的小幅调整。
- 第3周：只有反馈满足条件时才进行单变量调整。
- 第4周：巩固并完成周期复盘。

计划固定为4周。若训练中出现安全停止、修改健康/器械/时间答案，或接受周复盘调整，旧计划会失效或重新等待人工复核。

## 跟练、暂停和停止

1. 在“今天练什么”或“四周完整计划”选择训练节。
2. 点击“开始本节训练”，阅读安全确认后再开始。
3. 每屏只完成一个确定动作；按页面显示查看 GIF、剂量、RPE、休息、呼吸和疼痛边界。
4. 音乐可以播放、暂停和调整音量；音乐不可用不会阻止跟练或安全停止。户外活动保持低音量。
5. 完成最后一个动作后，系统自动记录整节完成。

### 普通退出

点击右上角关闭并确认普通退出：

- 不记录安全事件；
- 不使计划失效；
- 本节不算完成，可稍后重新开始。

### 因不适暂停/停止

点击“暂停 / 停止训练”并选择固定原因：

- 当前训练不记为整节完成；
- 严重信号会保存安全停止事件；
- 旧计划立即失效；
- 必须重新完成安全筛查。

出现下列任一情况立即停止训练：

- 胸部不适或压迫感；
- 明显晕厥感或已经晕厥；
- 异常气短；
- 突发剧痛；
- 无法承重；
- 意识或神经异常。

如有紧急症状，请联系当地急救服务。页面没有“忽略并继续”的入口。

新发关节不适时先停止当前动作，降低幅度或阻力；只有明确缓解才可返回。持续或加重时停止整节并重新筛查。

## 当天器械或场景发生变化

当前两人试用版**不提供训练当天的临时场景切换按钮**。不要自行把健身房动作替换成未审核动作：

1. 当天缺少计划要求的器械时，不开始该训练节。
2. 返回问卷修改场景/器械并重新确认。
3. 旧计划会失效，新计划必须再次经过 validator 和人工复核。
4. 若居家缺少弹力带等关键器械，当前版本可能原子阻断生成；这不是错误的半份计划，请联系试用负责人记录器械缺口。

## 每周复盘

1. 点击“第N周复盘”。
2. 填写固定选项：完成节数、未完成原因、整体难度、动作质量、疼痛变化、恢复状态和下周时间。
3. 查看“原计划 / 建议变化 / 原因”。
4. 选择“确认调整”或“保持原计划”；拒绝调整不会受到惩罚。
5. 接受调整后，新计划进入 `pending_review`，再次审核前训练入口关闭。
6. 新发/加重疼痛或影响日常活动时，系统优先要求重新筛查，不自动进阶。

## 数据和隐私

- 最终问卷、计划、训练记录和周复盘保存在当前浏览器的 `localStorage`。
- 未最终确认的问卷草稿只保存在当前标签页的 `sessionStorage`。
- 换浏览器、换设备、清理浏览器数据或使用隐私模式可能导致数据丢失。
- 数据不会自动同步或备份，也不会默认发送网络请求。
- 隐私区可以查看/下载最小审核摘要，并执行“删除本机全部数据”。
- 删除覆盖问卷、计划、训练记录、周复盘、旧追踪记录、音乐偏好和当前标签页草稿。
- 网页无法删除已经下载、复制、截图或发送的文件；请手动删除这些副本。

## 如何反馈问题

只在试用负责人指定的一对一微信会话反馈。优先提供：

- 参与者角色 A / B；
- ZIP 版本或构建提交；
- 页面/流程步骤；
- 最小复现步骤；
- 预期结果和实际结果；
- 操作系统、浏览器版本、屏幕尺寸；
- 不含健康内容的局部截图。

禁止发送姓名、电话、邮箱、原始问卷、具体病史、身体数值、完整 `localStorage`、控制台转储或未脱敏截图。若问题涉及健康或疼痛，只写“触发安全流程”，不要写具体症状史。
