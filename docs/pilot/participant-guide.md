# MOVE 28 两人试用参与者指南

> 这是邀请制产品试用，不是医疗诊断、治疗或康复服务。任何医生限制、身体警示信号或现实环境风险都优先于页面计划。

## 1. 从 HTTPS 链接进入

1. 只打开维护者单独发给你的 **HTTPS 试用网址**。
2. 使用同一台设备、同一个常用浏览器完成整个试用。
3. 不要使用隐私/无痕模式，不要主动清理该站点的浏览器数据。
4. 如果链接不是 `https://` 开头、浏览器提示证书风险或页面来源不明，先停止并联系维护者。

ZIP、压缩包和 `file://` 不是参与者入口。维护者可能保留离线备份，但参与者不需要下载或解压项目文件。

## 2. 完成问卷与能力校准

1. 点击“生成我的4周计划”。
2. 如实完成健康、时间、场景和器械问卷。
3. 继续完成三屏能力校准，共五项：坐站、髋铰链、墙壁推、地面活动、步行耐受。
4. 所有能力检查均为非极限检查，可以选择“未尝试/跳过”；不要为了得到更难计划而勉强测试。
5. 任一检查出现胸部不适、异常气短、突然剧痛、头晕/晕厥感、无法承重或神经/意识异常，应立即停止并按页面提示处理。如症状严重或疑似紧急情况，立即联系当地急救服务。

系统不会要求上传视频，也不会使用摄像头判断动作。

## 3. 等待人工一致性复核

问卷和能力档案完成后，系统只会生成候选 4 周计划。页面显示“人工一致性复核完成前不会开放训练入口”时属于正常状态。

- 只使用页面上的“下载复核 dossier”和“指定复核人入口”；不要尝试跳过复核。
- 按维护者约定，通过现场操作或一对一屏幕共享完成复核。
- 复核只检查规则、器械、能力约束、动作和剂量是否一致，不等于医疗许可。
- 当前本地动图视觉质量未达到公开产品标准，动作库和跟练页暂停展示GIF；实际动作执行以页面文字步骤、安全停止提示和复核意见为准。

## 4. 开始训练

人工批准后刷新页面：

1. 首页“今天练什么”出现“开始本节训练”。
2. 每屏只完成当前动作，按页面剂量、呼吸、安全提示和受控变式指导执行。
3. 按页面文字动作指导训练；在合格素材替换前，不依赖动图示范。
4. 音乐可关闭，音乐失败也不影响训练。
5. 训练中如出现胸部不适、晕厥感、异常气短、突发剧痛、无法承重或神经/意识异常，点击“暂停 / 停止训练”，不要继续。

## 5. 每周复盘

完成当前周后，在首页打开“第 N 周复盘”：

- 如实填写完成情况、难度、疼痛和恢复。
- 系统一次只允许一个受控变量变化。
- “保持原计划”不会改计划。
- 接受调整后，新计划会重新进入 `pending_review`；人工复核前训练入口再次关闭，这是安全硬门。

## 6. 数据、备份与删除

- 问卷、能力档案、计划和记录默认只保存在当前浏览器。
- 切换浏览器、清理站点数据、使用无痕模式或更换设备可能导致记录丢失。
- 待复核时页面可下载固定字段 review dossier；“本机数据与隐私”仍可下载更小的审核摘要。两者都不包含完整原始问卷。
- “删除本机全部数据”会删除该浏览器内的 MOVE 28 数据；已下载文件需自行删除。

## 7. 报告问题

请提供：

- 大致时间；
- 浏览器与设备；
- 所在步骤；
- 页面固定提示文字；
- 是否刷新、切换浏览器或清理过数据。

不要在普通群聊中发送完整健康问卷、浏览器存储内容或 review dossier。优先使用维护者约定的一对一渠道。
